# Environment Configuration - Next.js Dashboard

## Environments

| Environment | Application URL | Database | Environment Variables | Users |
|---|---|---|---|---|
| Local | http://localhost:3000 | PostgreSQL / Neon (local configuration) | .env.local | Developer |
| Preview | Vercel-generated preview URL | PostgreSQL / Neon (configured connection) | Vercel Preview: POSTGRES_URL, NEXT_PUBLIC_SUPABASE_URL, NEXT_PUBLIC_SUPABASE_ANON_KEY, AUTH_SECRET | Developer and reviewers |
| Production | https://ali-new-todo.vercel.app | PostgreSQL / Neon (configured connection) | Vercel Production: POSTGRES_URL, NEXT_PUBLIC_SUPABASE_URL, NEXT_PUBLIC_SUPABASE_ANON_KEY, AUTH_SECRET | Authorized users |

## Important Notes

- Local configuration is stored in .env.local and must not be committed.
- Vercel API inspection on 26 October 2026 found a single POSTGRES_URL secret entry targeting both Production and Preview. They therefore share the configured connection value, and Preview/Production database isolation is NOT established. Do not run migrations or destructive tests against Preview until a separate Preview connection is configured and verified.
- Vercel Preview deployment of commit e216b91 is READY. The earlier failed Production deployment on main (103bc150) failed because tables customers and invoices were missing during prerendering. The Preview build succeeding does not verify the runtime database schema.
- Supabase Auth is used for dashboard access.
- Preview URLs are generated by Vercel for deployments.
- Environment variable values and passwords must never be included in documentation.
- Access to each environment should be verified before release.
