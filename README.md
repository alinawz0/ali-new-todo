# Dashboard App

A dashboard application built with Next.js as part of the Next.js App Router course. The project includes invoice management and demonstrates modern web development practices.

## Live Demo

[Open the Dashboard App](https://ali-new-todo.vercel.app/)

## Features

- Create, edit, and delete invoices.
- Validate form input and display helpful error messages.
- Handle errors and missing invoice pages.
- Protect dashboard routes with authentication.
- Responsive dashboard interface.
- Deploy preview changes through Vercel.

## Technology Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Database:** PostgreSQL
- **Deployment:** Vercel
- **Version Control:** Git and GitHub

## Getting Started

### Prerequisites

Install Node.js and pnpm before running the project locally.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/alinawz0/ali-new-todo.git
   ```

2. Open the project directory:

   ```bash
   cd ali-new-todo
   ```

3. Install dependencies:

   ```bash
   pnpm install
   ```

4. Configure the environment variables using `.env.example` as a reference. Add the required database and authentication values to your local `.env` file.

5. Start the development server:

   ```bash
   pnpm dev
   ```

6. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Environment Variables

Check `.env.example` for the environment variables required by the application. Configure valid database and authentication credentials before running the app.

**Security:** Never commit passwords, API keys, or other secrets to GitHub.
